# Tempo V2 — Flexible Antagonist Workout Tracker

A self-contained, mobile-friendly tracker with interchangeable exercises for every movement slot. Its custom workout builder includes 461 exercises across 13 muscle groups, plus a custom-name fallback for movements not in the library.

## Run locally

Open `index.html` in any modern browser. No install or development server is required.

Workout data is stored in `localStorage` on the current browser and device. No account or server database is required.
